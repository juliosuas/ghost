# Security policy

## Reporting a vulnerability

Report security issues privately. Do not open a public GitHub issue.

- GitHub private reporting: https://github.com/juliosuas/ghost/security/advisories/new
- Maintainer GitHub profile: https://github.com/juliosuas

This project does not publish a security email address.

Describe the impact and how to reproduce it. Use synthetic data only (`demo_user`). Do not include real people.

## Scope

In scope: API token checks, secret handling, bind address, Docker exposure, and leaks of case-file data.

Ghost is a local tool. It has no telemetry and no auto-update channel. A request to add either is a product change, not a vulnerability report. See [CONTRIBUTING.md](CONTRIBUTING.md).
